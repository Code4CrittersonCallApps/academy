# Sheehan Academy

Self-paced adult courses from Sheehan Homestead (Callahan, FL). Founding beta v1.

- `/coding/` Code to Ship (12 modules) with worked examples in `/coding/examples/`
- `/languages/` Speak Any Language + Spanish Starter (11 modules) and `spanish-starter-deck.csv` for Anki
- Writing and Comedy: coming soon

Course content lives in each folder's `data.js`; `assets/app.js` renders tiles → module → lessons, exercise, quiz, resources. Progress is stored in the visitor's localStorage only.
